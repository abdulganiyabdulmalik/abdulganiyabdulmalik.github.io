Starting up…
NO KEYS

This tool never asks for a private key or seed phrase. Only a public Pi wallet address is needed to scan an account. If anything ever asks you for your seed phrase, close it — that's a scam.

01 Scan a wallet

Enter a Pi Mainnet public address (starts with G, 56 characters). This performs a read-only lookup against the public ledger.

02 Account overview

Balance, sequence number, and receive status from Pi Mainnet.

03 Security assessment

Heuristic checks based on public account data. This is informational only, not a guarantee of safety.

04 Recent transactions

Most recent activity for this account, with links to a block explorer.

05 Testnet payment demo

TESTNET ONLY

This section creates a Pi Testnet payment for development purposes. It only functions inside the Pi Browser with the Pi SDK sandbox enabled, and moves test Pi with no real value. Nothing here touches mainnet funds.

Backend calls this demo expects (implement these yourself — never in the browser): 
POST /api/payments/approve   { paymentId }   → calls Pi Server API "approve"
POST /api/payments/complete  { paymentId, txid } → calls Pi Server API "complete"

Your Pi Server API key lives ONLY on your server (env var / secret manager).
It must never appear in this file, in a bundled JS file, or in any
browser-visible network request.
